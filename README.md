**AI-ASSISTED VIDEO INTELLIGENCE**

<img src="https://img.shields.io/badge/VERSION-0.1-8A2BE2?style=flat-square"/>

</div>

An ongoing engineering project exploring how long-form videos can be transformed into short-form content through intelligent media processing.

### Implemented in v0.1

- FastAPI health endpoint
- Chunked video uploads
- File extension validation
- Collision-resistant storage names
- FFprobe metadata extraction
- FFmpeg audio extraction
- Provider-neutral transcription interface
- Unit tests for upload validation and storage paths
